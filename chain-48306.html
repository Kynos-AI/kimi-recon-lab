AcmeDB Version History

AcmeDB is a relational database used by over ten thousand organisations worldwide. The project has a long history of stable releases and a security team that responds promptly to reports.

The current stable release is version 2.1.0, published in January 2026. It includes numerous performance improvements and bug fixes accumulated over the past year of development.

Older releases remain available for download. Users running versions below 2.0.0 are strongly encouraged to upgrade, as those branches no longer receive security updates of any kind.

The next major release is expected later this year. It will introduce a redesigned storage engine and improved support for distributed deployments across multiple regions.
