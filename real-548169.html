Database Configuration Guide

This guide describes the configuration options for AcmeDB version 2.1.0 released in January 2026. All settings described here apply to the standard edition unless noted otherwise.

The maximum number of concurrent connections is controlled by the max_connections parameter. Its default value is 100, and the allowed range is from 10 to 1000. Setting it higher than the available memory allows will cause startup failure.

Connection timeouts are governed by connect_timeout, measured in seconds. The default is 30 seconds. Values below 5 are not recommended because they may cause spurious failures on high-latency networks.

Warning: setting max_connections above 500 without increasing the shared buffer pool may lead to out-of-memory conditions under sustained load.

For the enterprise edition, additional parameters are available. Consult the enterprise administration manual for the complete list of supported options.
